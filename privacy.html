Privacy Policy

Last updated: October 27, 2026

This notice applies to Visual Inspiration Agent, a personal, local-first software prototype by the developer foxiliuzi. The website and local application have different data-handling characteristics. Features that are still planned are identified below.

1. Website data

This website is static. It has no account-registration form, analytics script, or developer-operated database collecting visitor submissions. It may be served by GitHub Pages, which can process technical request information under GitHub's own policies.

2. Local application data

Users running the prototype on their own computers may enter creative descriptions, configure workflows, and supply images they are permitted to use. These inputs are handled locally. If users run ComfyUI, generated images and related files may be saved in their local ComfyUI output folders, as determined by their configuration.

3. Pinterest content

The application can create links to official Pinterest searches. Access to the Pinterest API, where available, requires the appropriate permissions and authorization. Intended uses are searching for visual ideas and displaying attributable source links.

  • No unauthorized scraping or bulk downloading of Pinterest content is performed.
  • Authorized Pin search results are intended for temporary display, not permanent API-data storage.
  • Displayed Pins link to the original Pinterest source.
  • Pinterest materials are not used to train, fine-tune, or develop AI models.

4. Credentials and account access

The current local prototype can read an optional Pinterest API access token provided by the user through local environment configuration. It does not request Pinterest passwords or submit credentials to this static website. An automated Pinterest OAuth connection is not yet provided by the website. This policy will be updated before introducing materially different authentication behavior.

5. Third-party services

Opening a Pinterest page or using an approved Pinterest API feature involves Pinterest and is subject to Pinterest's privacy policy. Hosting through GitHub Pages is subject to GitHub's privacy statement. Other locally installed tools may have separate license and data-handling terms.

6. Retention and choices

This website does not run a user-data database. Pinterest API responses are not intentionally persisted by the local prototype. Users control whether to open external links, provide their own images, execute generation tasks, retain generated local files, or grant and revoke eligible API access. Files created by a local workflow may be deleted by the user.

7. Children and changes

The prototype is not directed at children under 13. Any meaningful changes to data handling will be reflected here with an updated date.

8. Contact

For privacy inquiries, contact the developer through the project repository Issues after the public repository is created.
