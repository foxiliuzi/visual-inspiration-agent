Visual Inspiration Agent is an early-stage personal software project for discovering visual ideas, preparing structured scene layouts, and coordinating locally installed image-generation tools.

Prototype · Under development
Explore the workflowPrivacy Policy

Creator-controlled workflow

01 / DISCOVER

Find inspiration

Prepare thematic searches and open original Pinterest search results. Authorized API features will only be enabled when permission has been granted and original sources remain linked.

02 / COMPOSE

Plan a scene

Turn a user-written idea into editable scene descriptions and MOSS-compatible layout prompts. Users decide what concepts to use.

03 / CREATE

Render locally

Experiment with locally running ComfyUI workflows, including MOSS and Krea2. Integrated model orchestration is an ongoing prototype.

Independent project. Visual Inspiration Agent is not affiliated with or endorsed by Pinterest. It does not scrape Pinterest, bulk-download Pins, or use Pinterest materials to train or fine-tune AI models. Restricted API features require separate authorization.
